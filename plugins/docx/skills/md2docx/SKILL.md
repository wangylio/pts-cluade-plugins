# Markdown 转 Word 文档 (md2docx)

## 用途

读取一份 markdown 文件，以使用者提供的 `.docx` 模板为**唯一样式来源**，生成 Word 文档：

- 字体、字号、行距、多级标题编号、页眉页脚、页码 → 全部由模板决定
- 标题层级、段落、列表、表格、代码块、图片、封面、目录 → 全部来自 markdown
- 模板文件本身**不会被修改**，输出写入新文件

## 触发条件

- 使用者说「转成 Word」「导出 docx」「生成 word 文档」时使用。
- 使用者已生成 markdown 文档并需要交付 Word 版本时使用。
- 使用者说 `/md2docx` 时使用。

## 前置条件

| 依赖 | 检查命令 | 缺失时的处理 |
|------|----------|--------------|
| Python 3.x | `python --version` | 提示使用者安装 Python |
| python-docx | `python -c "import docx; print(docx.__version__)"` | 打印 `pip install python-docx` 后停止，**不自动安装** |
| Word（可选） | 仅在需要自动更新目录页码时使用 | 不可用时转换照常完成，提示手动更新域 |

## 准备模板

模板由使用者提供，建议放在 `plugins/docx/skills/md2docx/assets/template.docx`，也可用任意路径。

模板需要具备的样式（名称可用于中文版 Word 的显示名）：

| 用途 | 样式名（任一） |
|------|----------------|
| 正文 | `Normal` / `正文` |
| 标题 1~6 | `Heading 1`…`Heading 6` / `标题 1`…`标题 6` |
| 无序列表 | `List Bullet` / `列表项目符号` |
| 有序列表 | `List Number` / `列表编号` |
| 表格 | `Table Grid` / `网格型`；或自定义后改名 |
| 代码块 | `Code` / `代码`（内置模板无此样式，需自建） |
| 引用 | `Quote` / `引用` |
| 图题 | `Caption` / `题注` |
| 封面主标题 | `Title` / `标题` |
| 封面副标题 | `Subtitle` / `副标题` |
| 目录标题 | `TOC Heading` / `目录标题` |

缺失的样式会在转换结束时列出，对应内容降级为正文样式，转换不会中断。

## 调用方式

脚本位于本技能目录的 `scripts/md2docx.py`，用绝对路径调用：

```bash
python "<skill目录>/scripts/md2docx.py" --input "<markdown文件>" --template "<模板.docx>"
```

Windows 示例：

```bash
python "E:\Github\pts-cluade-plugins\plugins\docx\skills\md2docx\scripts\md2docx.py" ^
  --input "docs\电能表参数透传\PRD-电能表参数透传.md" ^
  --template "plugins\docx\skills\md2docx\assets\template.docx" ^
  --output "docs\电能表参数透传\PRD-电能表参数透传.docx"
```

### 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `--input` / `-i` | 是 | 输入 markdown 文件（建议 UTF-8） |
| `--template` / `-t` | 是 | docx 模板，仅提供样式 |
| `--output` / `-o` | 否 | 输出路径，默认与 markdown 同目录同名 `.docx` |
| `--h1-pagebreak` | 否 | 每个一级标题前自动分页（默认关闭） |
| `--skip-com` | 否 | 不调用 Word 更新目录域 |
| `--version` | 否 | 显示脚本版本 |

## markdown 约定

### frontmatter

文件顶部可带 YAML frontmatter（`docx` 插件的四个文档技能默认会写入）：

```yaml
---
title: 电能表参数透传功能 产品需求文档
doc-type: PRD
version: V1.0
author: 张三
date: 2026-10-28
confidentiality: 内部
cover: true
toc: true
---
```

| 字段 | 作用 |
|------|------|
| `title` | 封面主标题 |
| `doc-type` | 封面副标题，如 PRD / HLD / LLD / UM |
| `version` / `author` / `date` / `confidentiality` | 封面信息行 |
| `cover` | `true` 生成封面页，缺省不生成 |
| `toc` | `true` 在封面后插入目录域，缺省不生成 |

### 支持的语法

| markdown | 输出 |
|----------|------|
| `#` ~ `######` | 标题 1~6（编号由模板的多级列表提供） |
| 普通段落 | 正文；中文换行自动拼接，不插空格 |
| `-` / `*` / `+` | 无序列表（单层） |
| `1.` / `1)` | 有序列表（单层） |
| GFM 管道表格 | 表格，首行为表头并跨页重复 |
| ```` ``` ```` | 代码块，逐行套用代码样式 |
| `>` | 引用块 |
| `---` | 水平线（**不是**分页） |
| `\pagebreak` 或 `<!-- pagebreak -->` | 分页符 |
| `![图题](路径)` | 图片，按版心宽度缩放并居中，图题用题注样式 |
| `**粗体**` / `*斜体*` / `` `行内代码` `` | 行内格式 |

### 不支持

- mermaid、PlantUML 等图形块：**原样保留为代码块**，请改用文字、表格或本地图片
- 嵌套表格、嵌套列表、HTML 片段、脚注、公式

## 样式契约

md 结构 → 模板样式的映射是固定的，脚本不写死字体：

| md 元素 | 首选样式 | 说明 |
|---------|----------|------|
| 标题 1~6 | `Heading N` → `标题 N` | 缺该级时降级到更低级标题 |
| 正文 | `Normal` / `正文` | |
| 列表 | `List Bullet` / `List Number` | 缺样式时手工加 `•` 或 `1.` 前缀 |
| 表格 | `Table Grid` | 首行加粗且跨页重复 |
| 代码 | `Code` / `代码` | 内置模板通常没有，需在模板中自建 |
| 引用 | `Quote` / `引用` | 缺样式时左缩进 |
| 图题 | `Caption` / `题注` | |
| 封面标题 | `Title` / `标题` | 仅封面允许脚本设置字号（样式缺失时兜底） |
| 封面副标题 | `Subtitle` / `副标题` | |
| 目录标题 | `TOC Heading` / `目录标题` | |

内置样式优先于同名自定义样式（例如模板里的 `Caption` 会优先于自建的「题注」）。要改图题外观，请直接修改模板中的题注样式。

## 输出与验收

脚本结束会打印：

```
[完成] 已生成：<输出路径>
  模板：<模板路径>
  统计：标题 N 个，表格 M 个，图片 K 张
  缺失样式（已降级为正文样式）：<样式名列表>
  警告：<缺失图片等>
  <目录域更新结果>
```

交付前人工检查：

1. 字体、字号、行距、标题编号与模板一致
2. 封面信息与 frontmatter 一致，目录位置正确
3. 目录页码：若提示未能自动更新，打开文档后 `Ctrl+A` → `F9` → 更新整个目录
4. 表格表头、图片大小与位置、图题正常

## 故障排查

| 现象 | 原因 | 处理 |
|------|------|------|
| 提示未找到 python-docx | 依赖未安装 | 执行 `pip install python-docx` 后重试 |
| 文档样式全是默认字体 | 模板没提供样式，或样式名不匹配 | 按「准备模板」补齐样式；查看摘要中的缺失样式清单 |
| 标题没有自动编号 | 模板的标题样式未挂多级列表 | 在模板中给标题 1~3 配置多级列表编号 |
| 代码块没有等宽字体 | 模板缺少代码样式 | 在模板中新建 `Code`（或「代码」）样式 |
| 目录为空或显示占位文字 | 目录域未更新 | 打开文档 `Ctrl+A` → `F9`；或检查 Word 是否可用 |
| 图片没显示 | 路径相对 md 文件解析且文件不存在 | 修正图片路径，查看摘要中的警告 |
| 中文乱码 | md 不是 UTF-8 | 另存为 UTF-8 后重试 |
| 转换报模板不存在 | 模板路径错误 | 传入实际存在的 `.docx` |

## 注意事项

- **模板只提供样式**：不要在模板里放正文骨架；封面与目录由脚本按 frontmatter 生成
- **不自动安装依赖**：缺少 Python 或 python-docx 时只提示，由使用者自行安装
- **模板只读**：脚本以模板为底版加载后另存，不写回模板
- **不覆盖已有文件前先确认**：指定 `--output` 时若目标已存在，先向使用者确认再执行
- **转换后不要再用 Word 手工大改**：需要调整内容时改 markdown 再重新转换，避免两份内容分叉
- 目录页码依赖 Word 域更新，脚本只做 best-effort 更新，失败不影响文档生成
