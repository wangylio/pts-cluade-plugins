# 模板目录

`template.docx` 是 md2docx 的**默认底稿**，来自青岛鼎信 Q/DX 企业技术文档模板。

## 底稿的职责：骨架 + 样式

与「只提供样式」的普通模板不同，这份底稿自带文档骨架：

| 节 | 内容 | 转换时如何处理 |
|---|---|---|
| 第 1 节 | 封面页（Q/DX 标志、标准号、文档名称、发布/实施日期、发布部门、保密等级） | **保留**，只替换「文档名称」「发布日期」「保密等级」三处占位文字 |
| 第 2 节 | 目次页（「目　次」标题 + TOC 域） | **保留**，清空缓存条目并重建 TOC 域，由 Word 更新页码 |
| 第 3 节 | 正文（样例标题、段落、表格、变更记录） | **替换**：删除样例正文，改为 markdown 渲染结果；末尾保留「变更记录」标准表 |

每次转换都以底稿为母版另存为新文件，**底稿本身不会被修改**。

## 约束

- 转换要求底稿满足模板契约（必需样式见上一级 `SKILL.md` 的「模板契约」）。契约不满足时转换直接报错并列出缺失样式，不会降级拼装。
- 不要手工删除底稿中的分节符、封面元素或 TOC 域，否则三区定位会失败。
- 正文节里的「有序列表样式」示例段和带「序号」表头的样例表，是**有序列表缩进**与**表格列宽**的来源；调整缩进或列宽请直接改样例，脚本每次转换都会重新读取。
- 如需更换公司模板，替换本文件并同步更新 `SKILL.md` 的契约表与脚本中的 `STYLE_CONTRACT`。
